Support

Need help with InspectFold? Start with the common issues below or email support directly.

I cannot add photos

Check that InspectFold has the required photo or camera permission in iPhone Settings, then reopen the app and try again.

PDF export is not working

Make sure the report has the required information and that your device has enough storage space to generate the export file.

My signature is missing

Open the report again and add a signature before exporting. InspectFold includes a signature capture step inside the report flow.

How do I start a new report?

Create or open a property, choose a checklist, then start a new report from the report creation flow.

What is included in the free version?

InspectFold includes one free starter report flow so you can try the full reporting experience before upgrading to Pro.
